# DAW — Desarrollo de Aplicaciones Web

Ejercicios y prácticas del Técnico Superior en DAW (curso 2026-2027).

## Estructura

Una carpeta por asignatura y, dentro, una carpeta numerada por tema o práctica.
Cada práctica es un proyecto de IntelliJ o VSC independiente

```
bases-de-datos/
entornos-de-desarrollo/
itinerario-empleabilidad/
lenguajes-de-marcas/
modulo-optativo/
└── proyecto-mpo1/
programacion/
├── 01-primer-proyecto/       Primer programa: print, println, printf
├── 02-operadores/            Lectura por teclado (Scanner) y operadores
└── 03-estructuras-basicas/   Variables, tipos, nombres y constantes (ejercicios 1-5)
sistemas-informaticos/
```
